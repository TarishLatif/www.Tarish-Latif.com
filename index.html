Main Project

PDF Chatbot: RAG-Based AI Assistant

An intelligent PDF chatbot built with Retrieval-Augmented Generation. Users upload PDF documents and ask questions about their content.

The system retrieves the most relevant passages from the uploaded documents and passes them to an AI language model, which generates contextual, document-grounded responses.

Key features

  • PDF document processing
  • Text extraction & chunking
  • Embedding generation
  • Vector-based semantic search
  • Context-aware Q&A
  • RAG pipeline
  • Answers based on document content
